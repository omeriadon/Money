# Money

Track money | Analyse expenses | Budget better | watchOS support

For FlavorTown

## Main Features
- Simple home tab:
    - look at current financial status
    - add expenses/incomes quickly
- Analytics tab:
    - graph of income / outcome over time
    - category-wise expense analysis
- Settings to manage account
- Transactions list to easily edit or bulk-manage transactions

## To Build + Run
1. Clone the repo
2. Open `Money.xcodeproj` in Xcode on Mac
3. Select the target device/simulator
4. Press `Cmd + R` to build and run the app
